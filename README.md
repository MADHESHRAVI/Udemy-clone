# Udemy-clone
📚 Udemy Clone – Single Page Website

This project is a Udemy Clone Single Page Website created to replicate the basic UI and layout of the Udemy online learning platform. The entire application is built as a single-page website, focusing on frontend design and user experience.

🚀 Features

🏠 Single page layout

📖 Course cards display

🧑‍🏫 Course information section

🔍 Search bar UI

📱 Fully responsive design

🎨 Modern and clean user interface

🛠️ Technologies Used

HTML5

CSS3

JavaScript
